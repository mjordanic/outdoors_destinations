Support

GoFindMeAHike is free for everyone, and stays that way. If it helped you find a hike, you can leave a tip. Tips only cover hosting: the server that runs the search. A tip buys no extras; every part of the site is the same for everyone.

The Ko-fi page is not set up yet, so there is no tip link for now.
