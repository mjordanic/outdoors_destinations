# HikesAlike is the site's name

The public page is called HikesAlike, with the tagline "Hikes like the ones you love." It replaces GoFindMeAHike (ADR-0027); no domain is bought yet (update 2026-11-06: the site's address is now https://hikesalike.com, with contact@hikesalike.com as its contact). As before, the name is the brand of the site, not a domain term: a DayHike stays a DayHike in the code, the Catalog and GLOSSARY.md, and the `dayhike` package, CLI, Cloud Run service and repository keep their names. The page stays English only (ADR-0027).

The artwork is the captain's: `static/mark.svg` (the square tile, tab icon and header logo), `static/wordmark.svg` (mark, name, tagline and a line on what the site does; About page), and PNGs rendered from them, `apple-touch-icon.png` (180×180) and `social-preview.png` (1200×630, `og:image` and `twitter:image` on every page). The SVGs are the captain's files cropped to their art, paths unchanged.
