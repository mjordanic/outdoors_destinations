# External hike layers, starting with Ireland

Some countries have few OSM hiking relations but publish official trail registers as open data. Ireland's Sport Ireland trail register lists 1,029 walking trails under CC BY 4.0, and 72 % of their starts have no Trailhead within 1 km. Such registers can fill the thinnest countries, as long as their licences stay apart from the ODbL data. The big commercial platforms (AllTrails, Komoot, Wikiloc, Strava, Outdooractive) forbid reuse in their terms; the sources register (ADR-0060) records why each one is rejected.

**An external hike is its own record, beside the OSM ones.** An *external source* has a register id, a `fetch` step that caches its data as GeoJSON under `data/external/<source>/` (`dayhike fetch-external --source <id>`), and an adapter that reads the cached file into hikes. Each hike has a name, a line from its start, a stable record id and the record's page. `dayhike ingest --external <id>` adds each one as a DayHike of kind `external`, with `source` the register id, `source_ref` the record id and `source_url` its page. Ingest refuses a source the register does not list as `used`. An external hike never edits, merges into or borrows the geometry of an OSM hike. Its line is the source's own, with no OSM ways, so its GeometryStore rows are vertices only.

- **Licence model.** Under the OSMF's Collective Database guideline, an external layer that is kept as its own rows, each with its own geometry, is a separate database next to the OpenStreetMap one, and it keeps its own licence. The page credits each one from the register: the hike panel names the source and its licence and links the record; `credits.html`, `/api/info` (`attribution`) and the export's `meta.json` (`sources`) carry a credit per source; a GPX of an external hike credits the source, not OpenStreetMap. What HikesAlike computes for every hike (amenities near the start from OpenStreetMap, heights, land cover, climate) is computed for an external hike too, and those values keep the licences of their own sources.
- **Id.** A hash of `(source, source_ref)`, mapped into [2^39, 2^40): above every OSM relation id, below every built id (ADR-0038), and a JavaScript-safe integer. A rebuild from a newer copy of the source gives the same id to the same record, so a `#hike=` link survives.
- **Twin rule.** An external hike that is a Twin of a relation DayHike (the Twin rule of `similarity`) is dropped, and so is one that is a Twin of an external hike kept before it. When an official hike and an OSM hike are the same walk, the OSM hike is listed: it is ODbL data and it can be edited on the map. Only relation DayHikes that start near the external hikes, and whose length allows a Twin, are compared.
- **Floor.** The 1 km floor of ADR-0033 applies; there is no upper cap. A long official way is not cut into DayStages yet.
- **Unchanged downstream.** Sampling (DEM, WorldCover, CHELSA), similarity, Twins, Ranking, search and the serving export read an external hike as any other DayHike. Checked in code: the facts that read OSM way tags (SurfaceMix, TarmacApproach) are missing (NaN) for a hike with no ways, not zero, and its difficulty is missing (a source's own grading is not SAC). The page offers no "Edit on the map" for it: `/api/hikes/{id}` gives `built` as null, and its head links no OSM relation.

**First source: Sport Ireland Trail Routes** (`ie-sport-ireland`). The ArcGIS layer `GetIrelandActiveTrailRoutes`, fetched in WGS84 and filtered to `Activity = 'Walking'`. `TrailID` is the record id (`trail/{TrailID}`), `Website` its page, `Name` its name. The record's `Latitude`/`Longitude` is its start, so the line is turned to start at the end nearer it. A multi-part line keeps its longest part, joined to every part whose end lies within 50 m (the gap a main walk joins, ADR-0012); parts farther away are left out, as the TrailGraph would not walk the jump (ADR-0009).

**Consequences.** The Catalog `dayhikes` and the export `hikes` gain a nullable `source_url`; a Catalog or export from before reads it as none. The export format stays 5. The ingest report counts `external_added`, `dropped_external_twin` and `dropped_external_length`. Without `--external` the Catalog is the same as before, row for row. Finland (#127), Norway (#128) and South Tyrol (#130) are each one more adapter in `EXTERNAL_SOURCES` and one more register row turned `used`.

**Considered Options**

- **Merge an official hike into the OSM hike it matches.** Rejected: the row would mix ODbL and CC BY data, which is what the Collective Database guideline keeps apart.
- **List the official hike, not the OSM one, when both are the same walk.** Rejected: the OSM hike is the one a visitor can edit on the map and that other OSM-built hikes refer to.
- **List both.** Rejected: Ranking would show the same walk twice. Twins in a Ranking are already grouped, but search and the map would still show two hikes on one line.
- **Snap the official line onto OSM ways.** Rejected: the hike would then be made from OSM geometry, which is a different licence and a different walk from the one the source publishes.
