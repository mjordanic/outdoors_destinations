# GoFindMeAHike is the site's name; English only for now

The public page is called GoFindMeAHike (domain gofindmeahike.eu, not bought yet). The name is the brand of the site, not a domain term: a DayHike stays a DayHike in the code, the Catalog and this glossary, and the `dayhike` package, CLI and Cloud Run service keep their names. The page is in English only for now, so it has no translation layer, locale switch or translated strings.

**Considered Options**: keep "DayHike Finder" as the page name; add i18n scaffolding now for later languages. Rejected: the captain chose the GoFindMeAHike brand, and a translation layer with one language is code to maintain with nothing to show for it.
